# TECNOLOGIAS PARA TO-DO LIST

### 1. HTML5 (Estrutura)
- `<form>` e `<input>`: Captura do texto da tarefa.
- `<button>`: Para interagir com o front-end.
- `<div>` e `<p>`: Exibição da lista de tarefas.

### 2. CSS3 (Estilo)
- Classes CSS: Estilização visual (ex: riscar tarefa concluída).
- Layout

### 3. JavaScript (Lógica)
- Manipulação do DOM: Criar e remover itens na tela.
- Eventos: Capturar cliques e envios do formulário.
